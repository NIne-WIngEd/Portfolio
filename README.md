# Mostakim Khan Rayan — Portfolio

A five-page static portfolio: Home, Work, Research, About, and Recognition.
Published at https://nine-winged.github.io/Portfolio/ through GitHub Pages from `main`.

## Local preview

Run `python -m http.server 8047 --bind 127.0.0.1` in this directory and open http://127.0.0.1:8047/.
No build step, package installation, external fonts, or third-party animation libraries are required.

## Editing

Content lives directly in the five HTML files and stays readable without JavaScript.
Shared styling is in `assets/css/styles.css`. `assets/js/main.js` adds the mobile menu,
project filters and a native canvas contour animation. Motion respects reduced-motion
preferences, has an explicit pause control, and stops when off-screen or the tab is hidden.
The resume download is `assets/docs/Mostakim_Khan_Rayan_Resume.pdf`.

Research status and project evidence were reviewed in October 2026. SoftwareX is a
submission with a revision invitation; the AFM preprint is on SSRN. The personal-AI
project remains in development. Open cuML contributions are distinguished from merged
Iris and RAFT contributions. Update those statuses as evidence changes.
