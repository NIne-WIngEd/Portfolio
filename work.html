AI In development

Sleight AI

Personal AI with memory, models and a clear owner.

  • Built Alice’s memory contracts around source provenance, versioning, owner permissions, correction and deletion.
  • Trained a 267.5M-parameter conditional decoder for 20 epochs on 36,597 public language pairs, using frozen Gemma features.
  • Assembled a 278.4M-parameter successor and verified checkpoint reloads. Its new reference and copy heads still need training.
  • FloRA’s prototype is covered by 1,047 contract tests and 38 core integration cases, including restarts.
What is established so far +

The decoder is a trained component, not a base language model trained from scratch. A three-stage personality candidate also reproduced 60 saved responses and decisions after a checkpoint reload; that checks reproducibility, not held-out personality accuracy.

Personal fidelity and the full FloRA behavioral comparison remain under evaluation. The larger goal is a personal AI that can keep useful context and act with its owner’s control.

Research Research software

AFM Morphology Platform

Less manual image analysis. More time to investigate the material.

  • Connected a Flask API and Next.js interface to classification, segmentation, editable masks, batch morphology analysis and PDF reports.
  • Reduced analysis turnaround by 65% in the lab workflow.
  • On a 50-image validation set: 90.0% classification accuracy, 0.845 mean Dice, 0.737 IoU and 6.66 images per minute.
Research and reproducibility +

First and corresponding author of the platform manuscript. The preprint is public on SSRN, and the SoftwareX submission has a revision invitation.

The evaluation data and compatible runtime are public. The original training dataset was not preserved, so the release supports evaluation and use rather than a complete retraining claim.
